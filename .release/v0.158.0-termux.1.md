# codex-termux 0.158.0-termux.1

Upstream: `rust-v0.158.0`.

## New upstream

- TUI: configurable right-click paste in the fullscreen view, composer support
  for prompt suggestions, and Mermaid flowcharts that accept quoted labels and
  ampersands.
- Agent message boards: an in-memory board for ephemeral sessions, an HTTP
  client for remote boards, and model-specific tool descriptions. The new
  `agent-message-board-client` crate travels in this build.
- Plans: Pro Max support and updated Pro display names.
- Runtime: early yielding for code-mode observations, startup-only PID
  namespace inheritance in exec-server, multi-agent spawn latency and failure
  metrics, and executor capability discovery V2 infrastructure.
- MCP: client secrets for pre-registered OAuth clients and diagnostic reasons
  on attribution errors.

## Fork guard updates

- Termux: restore native daemon startup and private sockets (#28, thanks @PeiPei233).
  On Android the shared daemon socket directory is the app-private
  `/data/data/com.termux/cdx-<uid>` instead of `/tmp`; `prepare()` reuses the
  binary selected by the npm launcher instead of staging it under the managed
  package root, and PID records are read and verified from `/proc/<pid>/stat`,
  which Android's `ps` cannot provide. Carried as patch #16 with its own
  anchors and regression tests.
- The guardian model-message cap keeps its fail-closed call shape after the
  upstream signature change: the review session builds its node REPL policy
  with the model slug and propagates the validation error, and the test the
  fork added follows the new signature.
- The cross-fork ENOTSUP lock inventory is re-verified on the merged tree: all
  call sites degrade by runtime error kind, never through a
  `cfg!(target_os = "android")` gate.
- Android V8 is unchanged: `v8 = "=150.4.0"` and its sandbox profile are the
  same as the previous release, so no new prebuilt is produced for this merge.

## Dependencies

- The workspace moves to `0.158.0`; the npm version carries the fork suffix
  (`0.158.0-termux.1`) while the binary keeps reporting the upstream version.
- The new agent message board crate and the MCP OAuth additions are the new
  dependency surfaces exercised by the Android release build before any
  publish.
