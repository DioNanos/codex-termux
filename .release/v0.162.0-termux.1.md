# codex-termux 0.162.0-termux.1

Upstream: `rust-v0.162.0`.

## New upstream

- Merges upstream tag `rust-v0.162.0` into the Termux fork (jump from
  `rust-v0.160.0`; the 0.161 line was skipped).
- Remote control: automatic reconnects back off with jitter, and a plain
  `codex remote-control` starts or reuses the managed daemon when daemon
  auto-start is on (`--no-daemon` keeps the foreground server).
- Daemon: installer errors are included in update failures, the control-socket
  lock files are cleaned up, and the file descriptor limit is raised on Unix.
- TUI: transcript selection and `/copy`, clickable URLs, and API-key accounts
  can use Daybreak.
- Workspace version stays at 0.162.0; the npm package carries the fork suffix.

## Fork updates

- Android: the SELinux process context is exported as
  `TERMUX__SE_PROCESS_CONTEXT` at startup, before any thread exists, when it is
  missing. Without it termux-exec's `execve()` hook can block a forked child
  forever (termux/termux-exec-package#41), and that child keeps the daemon's
  control socket open so a restarted daemon cannot bind it.
- Daemon: `daemon stop` also stops the update loop, the update loop ends when
  the fork refuses a standalone update instead of retrying forever, the updater
  pid record is removed when the updater exits, and a socket path longer than
  the platform limit is reported with its limit.
- Android packages are accepted without a bundled ripgrep; install it with
  `pkg install ripgrep`.
- File locks keep degrading on storage that does not implement them, now
  including the control-socket lock paths of this upstream release.
