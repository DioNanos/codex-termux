# codex-termux 0.162.1-termux.1

Upstream: `rust-v0.162.1`.

## New upstream

- Merges upstream tag `rust-v0.162.1` into the Termux fork (two fixes over
  `rust-v0.162.0`).
- TUI: multiline asynchronous question titles are wrapped and annotated per
  logical line, preserving blank lines, LF/CRLF endings and complete hyperlink
  destinations (openai/codex#51866).
- Daemon: shared-service features are checked only when explicitly overridden
  on the command line, so differences from configuration files or defaults no
  longer trigger a compatibility warning or restart request
  (openai/codex#52648).
- Workspace version stays at 0.162.1; the npm package carries the fork suffix.

## Fork updates

- CI: the embedded-server cell context gate (a launch with a cell isolation
  context never attaches to the shared daemon) is guarded in
  `verify-patches.sh`, and its dedicated integration suite now runs in CI.
- Tests: the upstream scheduled-update tests are marked ignored with the
  reason on the attribute; they need the standalone installer this fork
  refuses.
- Tests: the `daemon_startup` fixture stages its selection under
  `packages/app-server-daemon-termux` and writes the `codex-package.json`
  manifest with variant `codex-termux`, so every test exercises the fork's
  real package and state paths.
