## Codex Termux 0.155.0 — upstream rust-v0.155.0 and coordinated rollout writers

This release integrates upstream OpenAI Codex `rust-v0.155.0` and carries the
Termux filesystem-lock guarantee onto the relocated writer-lock module.

Upstream moved the thread writer lock into the rollout crate to coordinate
rollout compression with active thread writers. On Termux storage backends
advisory file locking can be unsupported at runtime, and this distribution
treats that case as a degradation rather than a failure; the classifier, its
call sites and its regression test now live in the relocated module, and the
release guard that protects them points at the new path. Deny-read policies
stay fail-closed and platforms that can sandbox keep identical behavior.

The managed daemon keeps its fork-owned no-updater policy: `daemon update`
fails closed and points users at the npm channel instead of starting an
updater, and the release tests pin that contract, including that no updater
process is spawned on a managed start.

The Android release profile builds with codegen-units=4 (upstream default),
down from 16 in 0.153.3; the packaging and npm channel are unchanged from
0.154.0.

## Upstream highlights of 0.155.0

- Voice conversations are exposed behind experimental features and gain a
  dedicated audio host process. The voice host is not part of this package, so
  `/voice` is not available on Termux.
- Guardian review settings, execution and reporting move into dedicated
  crates, with retries and failure reporting reworked.
- Managed app-server daemon: saved threads are restored on restart, recovery
  candidates are recorded on shutdown, and the launched executable identity is
  recorded in PID files.
- Rollout compression is coordinated with active thread writers, and a
  compressed rollout that cannot be searched no longer aborts the search.
- Filesystem sandbox hardening: WSL interop escapes are blocked from restricted
  sandboxes, Windows sandbox identity and permissions are fixed, and deny-read
  glob planning moves into the protocol crate.
- Network approval reviews are tied to their originating execution.
- TUI: streaming reasoning summaries in the status row, completion timestamps
  after successful turns, and reasoning effort preserved across compaction.
- App-server APIs for stored thread attachments, plus a bounded stdio shutdown
  that handles Unix SIGTERM gracefully.

## Compatibility

- The package remains `@mmmbuto/codex-cli-termux` for Android ARM64
  (Android 10+ / API 29+).
- The Termux build compiles `codex-cli` and `codex-code-mode-host` only, so the
  new voice host and its desktop audio stack are not built and `/voice` is not
  available in this package.
- The upstream base is OpenAI Codex `rust-v0.155.0`:
  https://github.com/openai/codex/releases/tag/rust-v0.155.0
