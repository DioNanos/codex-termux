# v0.146.1

Candidate Android Termux release of `@mmmbuto/codex-cli-termux`, synchronized
to upstream OpenAI Codex `rust-v0.146.1`.

## Candidate scope

- Integrates the upstream `rust-v0.146.1` patch release: a backport of the
  safer cyber-model auto-review defaults (`#37057`). The merge touched no
  fork-owned path; the only conflict was the workspace version.
- Preserves browser login, real in-process V8 code-mode, Termux TLS roots,
  Android lock and PTY compatibility, fork-owned update and installer channels,
  and the bundled `libc++_shared.so` runtime with `RUNPATH=$ORIGIN`.
- Keeps the Termux release profile explicit: thin LTO, 16 codegen units, and
  only the required `zip` compression features.

## Fork-side fix included

- `scripts/build_rusty_v8_android.sh` now ships the `v8_String_WriteFlags_*`
  compatibility aliases in the **published** binding. The patch was applied
  only to the checkout's `src/binding.rs`, which makes the crate compile on the
  build host, while consumers fetch the generated binding verbatim with a
  pinned SHA-256. A prebuild produced from a clean run therefore failed the
  Android build on undeclared symbols; the `v149.2.0` artifact had been fixed
  by hand before upload and nothing recorded it.
