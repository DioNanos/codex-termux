# v0.146.1

Android Termux release record for `@mmmbuto/codex-cli-termux`, synchronized to
upstream OpenAI Codex `rust-v0.146.1`.

## Release scope

- Integrates the upstream `rust-v0.146.1` patch release: a backport of the
  safer cyber-model auto-review defaults (`#37057`). The merge touched no
  fork-owned path; the only conflict was the workspace version.
- Preserves browser login, real in-process V8 code-mode, Termux TLS roots,
  Android lock and PTY compatibility, fork-owned update and installer channels,
  and the bundled `libc++_shared.so` runtime with `RUNPATH=$ORIGIN`.
- Keeps the Termux release profile explicit: thin LTO, 16 codegen units, and
  only the required `zip` compression features.

## Fork-side fix included

- `scripts/build_rusty_v8_android.sh` now ships the `v8_String_WriteFlags_*`
  compatibility aliases in the **published** binding. The patch was applied only
  to the checkout's `src/binding.rs`, which makes the crate compile on the build
  host, while consumers fetch the generated binding verbatim with a pinned
  SHA-256. A prebuild produced from a clean run therefore failed the Android
  build on undeclared symbols.
- The Android arm64 `rusty_v8` prebuild for `150.4.0` is published for the next
  upstream line, which moves off `149.2.0`.

registry and GitHub Releases are authoritative for live publication status. The
