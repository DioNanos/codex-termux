# v0.148.0

Candidate Android Termux release of `@mmmbuto/codex-cli-termux`, synchronized
to final upstream OpenAI Codex `rust-v0.148.0`.

## Candidate scope

- Integrates the final upstream `rust-v0.148.0` release: Markdown conversation
  export from the TUI with `/export`, session forking through `codex exec
  fork` plus archiving and restoring sessions from the resume picker, prompt
  drafting while the TUI initializes, estimated thread credits or cost in
  `/status` and status lines for eligible workspaces, Amazon Bedrock Runtime
  as a built-in provider, asynchronous hook commands with MCP tool
  invocation, and upstream fixes including resumed sessions restoring their
  persisted working directory and approval policy, turn reconnection through
  temporary provider outages, MCP recovery after OAuth reauthentication,
  fail-closed sandbox handling of denied or unreadable paths, and composer
  fixes for CRLF pastes and long URLs.
- Preserves browser login, real V8 code-mode with the sandboxed Android
  prebuilt and the packaged `codex-code-mode-host`, Android lock and PTY
  compatibility, fork-owned update and installer channels, and the bundled
  `libc++_shared.so` runtime with `RUNPATH=$ORIGIN`.
- Keeps the Termux release profile explicit: thin LTO, 16 codegen units, and
  only the required `zip` compression features.
- Bumps the Cargo workspace and npm package versions to `0.148.0`.

## Publication gate

This note is a release candidate record, not a publication claim. Before any
tag, GitHub release, or npm dist-tag change, the sanitized public candidate
must pass artifact, checksum, identity, install-smoke, and Android device
validation.

## Source validation

- `verify-patches.sh` passes against the complete Forge tree, and the
  sanitized public candidate passes it with `CODEX_PUBLIC_SANITIZED_TREE=1`.
- No local build or test backs this record: compilation and test evidence is
  expected from the release CI and the independent audit.

## Install after publication

Requires Android 10 / API 29 or newer on ARM64 Termux.

```bash
npm install -g @mmmbuto/codex-cli-termux@latest
codex --version
```
