## Codex Termux 0.154.0 — upstream rust-v0.154.0 and sandbox-honest apply_patch

This release integrates upstream OpenAI Codex `rust-v0.154.0` and completes
the approval-gated sandbox story for native Termux builds.

`apply_patch` on a platform that cannot provide a filesystem sandbox now
honours an explicit approval before bypassing it, and Update/Delete
pre-verification reads fall back to unsandboxed host reads only where no
sandbox can exist and the active policy has no denied-read restrictions —
fixes #25 (and closes the follow-up to #22). Deny-read policies stay
fail-closed and platforms that can sandbox keep identical behavior.

The TUI now drains queued input after a local compaction instead of leaving
the composer frozen behind an orphan pending-start latch; the launcher
postinstall validates `$PREFIX` before rewriting shebangs; and the daemon
README keeps the upstream exec-server attachment note.

## Upstream highlights of 0.154.0

- GPT-6-Astra is available in the model picker and Amazon Bedrock catalogs.
- Experimental worktree support: isolated checkouts via `--worktree` or
  `/worktree`, with browsing and resume.
- Inline asynchronous questions while Codex keeps working, with suggested
  choices or custom text.
- Windows sessions share a background Codex server, with daemon lifecycle
  commands and managed updates.
- Vim `R` replace mode with undo and dot-repeat, and `/copy` can copy
  status output or individual session fields.

## Compatibility

- The package remains `@mmmbuto/codex-cli-termux` for Android ARM64
  (Android 10+ / API 29+).
