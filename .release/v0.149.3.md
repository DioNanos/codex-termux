# [0.149.3] - 2026-08-27

Fork patch release aligned with the upstream OpenAI Codex `rust-v0.149.1`
base. The fork version is independent of the upstream line: npm and Cargo now
carry the same number so TUI and doctor no longer report a false update on a
fresh install.

## Fixed

- `apply_patch` honours an explicit user approval where no sandbox can exist by
  construction (Android/Termux): no approval is discarded into an unenforceable
  sandbox request, a failure unrelated to sandboxing after the bypass stays a
  normal failed tool call, and deny-read filesystem restrictions still block
  every bypass path (#22).
- Release contract provenance: a checkout without upstream `rust-v*` tags now
  declares that the base tag cannot be verified instead of failing; when tags
  are present the exact base tag is still required.
- Version alignment: the npm package version and the Cargo workspace version
  coincide at 0.149.3.

## Compatibility

- The package remains `@mmmbuto/codex-cli-termux` for Android ARM64.
