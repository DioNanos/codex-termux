# [0.150.1] - 2026-08-29

Final release of the fork, aligned with the upstream OpenAI Codex `rust-v0.150.1`
base. **This is the last release: the fork and its npm package are end-of-life
after it.** No further upstream alignments, features, bug fixes, or support are
planned. Existing releases remain available as-is for installation and
reference. Active development continues on
[codex-vl](https://github.com/DioNanos/codex-vl), an independent distribution
that keeps its own improvements (including Android/Termux support) without
tracking upstream release-by-release.

## Fork fixes carried in this release

- **AGENTS.md discovery notices files created mid-session (#14).** `/init`
  writes AGENTS.md into a session that started without one; discovery now
  re-runs while nothing has been found instead of serving a stale empty cache.
- **Background-terminal polling no longer animates the status indicator (#16).**
  While the session only waits on background terminal output, the indicator
  reports a dedicated "Waiting for background terminal" header and the
  animation rate keys off that exact state, instead of redrawing at full frame
  rate on an idle screen (measurable CPU burn on Android).
- **Remote attachment paths resolve to the client's real files (#21).**
  app-server maps `/tmp/codex-remote-attachments/...` paths back to the
  filesystem watcher and turn processor so attachments arrive where the client
  put them.
- **`apply_patch`/exec approval is honoured where no sandbox can exist by
  construction (#22).** On Android an approved command takes the unsandboxed
  path instead of being refused by an executor that cannot enforce a sandbox;
  deny-read restrictions still block every bypass path. (First shipped in
  0.149.3; part of the final delta.)

## Upstream alignment (rust-v0.149.1 -> rust-v0.150.1, ~208 commits)

Among the upstream changes carried by this alignment:

- remote compaction now counts retained images toward its token budget by
  default, trimming older images as needed (#41003);
- agent role loading extracted into a dedicated crate; multi-agent v2 reloads
  children through their parent;
- Guardian session isolation and structured approval reviews hardened;
- hooks for interrupted turns and memory consolidation scoping;
- managed AWS access keys for Amazon Bedrock; OTEL turn-cost metric;
  vim dot-repeat; clickable Markdown links in supported terminals.

## Compatibility

- The package remains `@mmmbuto/codex-cli-termux` for Android ARM64
  (Android 10+ / API 29+).
- Update diagnostics stay on fork-owned channels; the base upstream release is
  declared in the package description and in these notes.
