# codex-termux 0.163.0-termux.1

Upstream: `rust-v0.163.0`.

## New upstream

- Merges upstream tag `rust-v0.163.0` into the Termux fork (232 upstream
  commits over `rust-v0.162.1`).
- TUI: `/config` searches preferences across categories and applies supported
  settings immediately (openai/codex#52990, openai/codex#53429); a follow-up
  sent while Codex is responding steers the turn immediately, and interrupting
  also stops active Code Mode cells (openai/codex#51812, openai/codex#51835);
  `/keymap` gains a configurable leader key (openai/codex#52273).
- Daemon: a managed background server can be restarted from `/daemon` with a
  warning about interruptible work (openai/codex#53173), and the discovered
  daemon restart path is covered by tests (openai/codex#53631).
- Independent read-only tools, including skill, memory, and conversation
  history lookups, can run in parallel (openai/codex#52245).
- Bug fixes: resuming a saved thread restores its permissions and network
  approvals (openai/codex#53150); the network proxy checks permission before
  DNS lookups and rejects duplicate `Host` headers (openai/codex#51650,
  openai/codex#52661); local commands finish promptly when a child keeps an
  output pipe open (openai/codex#52652); `codex exec` no longer repeats a file
  diff after an unrelated command (openai/codex#53444).
- Upstream no longer bundles a patched `zsh`: Codex uses its standard shell
  executor, and configurations using the retired shell flags receive a
  migration notice (openai/codex#52160, openai/codex#52213). This fork had no
  patches of its own on that backend, so the removal is taken as is.
- Workspace version stays at 0.163.0; the npm package carries the fork suffix.

## Fork updates

- Merge resolution keeps the fork's `CODEX_SELF_EXE` resolution for the arg0
  aliases alongside the new upstream `main_execve_wrapper_exe` field, keeps
  the vendored-OpenSSL Android build block, keeps the fork's sandbox
  semantics (a platform without a sandbox backend by construction honors an
  approved escalation through the unsandboxed path) now that upstream moved
  `SandboxOverride` into the protocol crate, and keeps the managed-daemon
  README and the Termux state-directory test paths, including the new
  discovered-daemon restart branch.
- CI: the inherited Bazel jobs are disabled with the reason recorded on each
  block, the Bazel wait is removed from the blocking CI gate, and `docs/ci.md`
  documents what runs on this fork and why.
