# codex-termux 0.156.1

Upstream: `rust-v0.156.1`.

## New upstream

- GPT-6 family: `gpt-6-astra`, `gpt-6-sol` and `gpt-6-luna` join the model
  catalog; `gpt-5.4-mini` maps to `gpt-6-luna` at startup. (Astra was already
  visible in this fork; Sol and Luna are new.)
- Daemon-managed installs gain an updater loop with release restore and a
  migration from the legacy standalone layout. In this fork the whole flow is
  fail-closed: the standalone installer refuses to fetch the upstream script
  (see below) and daemon self-update reports the fork npm channel.
- New workspace crates ship in the binary: `tcp-tunnel`, `mermaid`,
  `agent-message-board`. New dependency chains (`h3`, `h3-quinn`,
  `rustls-platform-verifier(-android)`) are exercised by the Android release
  build before any publish.
- Windows voice packaging (third_party/voice) is upstream-only; no fork delta.

## Fork guard updates

- The standalone auto-updater guard moves with the upstream rewrite: the fork
  still refuses to fetch or execute the upstream install script
  (`install_latest_standalone` fails closed naming the fork package), daemon
  update requests route through the fork npm channel, and the regression test
  pins the fail-closed behaviour (`install_latest_standalone_is_disabled_in_fork`).
- The 8 KiB model-message cap follows the upstream `ResolvedModelMessages`
  refactor: validation now runs where the resolved messages are built
  (`guardian_node_repl_policy`, persistent mode) and the remote catalog loader
  keeps dropping only the oversized model instead of the whole catalog.
- The AGENTS.md disk-discovery fix (upstream issue #37704) is re-applied on the
  new refresh flow: repository discovery is skipped only once instructions have
  actually been found, so `/init` after startup is picked up.
- The status-indicator watch: the background-terminal 200 ms frame
  branch is re-applied on top of the upstream progress/shimmer condition, with
  the regression test updated to the new helper.
- Sandbox bypass for platforms with no backend (fork fix #22) preserved on the
  new orchestrator decision path.

## Dependencies

- `rustls` 0.23.45 line continues; new native-facing crates above are the
  build-risk items for the Android release CI.
