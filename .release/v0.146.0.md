# v0.146.0

Candidate Android Termux release of `@mmmbuto/codex-cli-termux`, synchronized
to final upstream OpenAI Codex `rust-v0.146.0`.

## Candidate scope

- Preserves browser login, real in-process V8 code-mode, Termux TLS roots,
  Android lock and PTY compatibility, fork-owned update and installer channels,
  and the bundled `libc++_shared.so` runtime with `RUNPATH=$ORIGIN`.
- Keeps the Termux release profile explicit: thin LTO, 16 codegen units, and
  only the required `zip` compression features.
- Includes upstream 0.146.0 workspace additions and lockfile resolution.
- Keeps the daemon's standalone installer fail-closed: the Termux update loop
  does not fetch or execute upstream installer code.

## Publication gate

This note is a release candidate record, not a publication claim. Before any
tag, GitHub release, or npm dist-tag change, the sanitized public candidate
must pass artifact, checksum, identity, install-smoke, and Android device
validation.

## Source validation

- `verify-patches.sh` passes against the complete Forge tree.
- `cargo check -p codex-tui -p codex-core` passes for the integrated source.
- `cargo test -p codex-app-server-daemon update_loop --lib` passes 4/4,
  including the Termux standalone-installer no-op contract.
- The npm dry run identifies `@mmmbuto/codex-cli-termux@0.146.0`; no Android
  ELF artifact is claimed until a sanitized release build and device smoke are
  available.

## Install after publication

Requires Android 10 / API 29 or newer on ARM64 Termux.

```bash
npm install -g @mmmbuto/codex-cli-termux@latest
codex --version
```
