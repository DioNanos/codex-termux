# v0.145.0

Stable Android Termux release of `@mmmbuto/codex-cli-termux`, synchronized
directly with upstream OpenAI Codex `rust-v0.145.0`.

## Highlights

- Preserves the complete Android/Termux compatibility layer while integrating
  the final upstream stable release without carrying parallel alpha-only
  installer or updater surfaces.
- Keeps browser login, self-update, feedback, doctor, install scripts, and
  release links on the `DioNanos/codex-termux` and
  `@mmmbuto/codex-cli-termux` channels.
- Runs real in-process V8 code-mode (`exec`/`wait`) on Android using the
  fork-owned `aarch64-linux-android` `rusty_v8` artifact.
- Bundles `libc++_shared.so` and builds the native ELF with
  `RUNPATH=$ORIGIN` for direct invocation from Termux.
- Points `CODEX_SELF_EXE` at the native ELF so hidden `apply_patch` and
  re-exec aliases retain their special `argv[0]` instead of traversing the
  shell wrapper.
- Retains the Termux MCP environment and TLS-root compatibility fixes, PTY
  shim, scoped file-lock tolerance, and remote-control daemon support.
- Includes the complete Apache `LICENSE` and project `NOTICE` in the npm
  archive alongside the native payload.

## Install

Requires Android 10 / API 29 or newer on an ARM64 Termux installation.

```bash
npm install -g @mmmbuto/codex-cli-termux@latest
codex --version
```

## Release verification

- The immutable Android ARM64 npm tarball is built by GitHub Actions from the
  sanitized public candidate and published locally only after archive, ELF,
  checksum, identity, and install-smoke verification.
- `verify-patches.sh` validates the full Forge tree and the public tree with
  the explicit sanitized-tree contract.
- A SHA-256 checksum file is attached alongside the npm tarball.

## dist-tags

- The conservative `stable` tag remains on `0.144.4`.
